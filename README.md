# The Growth Challenge: what goes with paying

An independent submission by Andre Nwofor for the Carepatron AI Growth Marketer internship. It is not an official Carepatron site.

The site answers the five parts of the challenge on one page:

1. **Read the data.** What, in a practice's first 14 days, goes with paying, and how confident each finding is.
2. **Design one journey.** A behaviour-triggered journey with a holdout and a measurement plan.
3. **Write one message.** Email 1 from that journey, annotated.
4. **Ship something.** Open Slot, a free booking-link kit, live and embedded in the page (also at `tool/`).
5. **Tell us about the AI.** Tools, method, and where the AI got something wrong.

**Live site:** link to be added once published.

The data is fictional sample data supplied by Carepatron for the challenge.

## Every number is reproducible

No figure on the site is typed in by hand. `analysis/analysis.py` computes every number from the raw CSVs into `data/findings.json` (and `data/findings.js`, the same data for the page), and the page reads them from there.

```bash
pip install pandas numpy scipy statsmodels
python3 analysis/analysis.py --check       # recomputes everything; fails if findings.json has drifted
python3 analysis/verify_site.py index.html assets/js/*.js tool/index.html   # flags any number not in findings.json
python3 analysis/check_bindings.py index.html                                # checks each bound number is the right one
```

`verification.md` records every check, including a table that maps each statement on the page to its claim in `content/copy-and-claims.md`.

## Run it locally

It's a static site with no build step:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Layout

```
index.html                 the site (single page)
assets/css/style.css       styles and design tokens
assets/js/charts.js        one function per chart; values come only from findings
assets/js/main.js          number binding, nav, journey stepper, demo frame, motion
data/findings.json         generated by analysis.py; the single source of truth
data/findings.js           the same data as window.FINDINGS
data/raw/*.csv             Carepatron's sample data (fictional)
analysis/analysis.py       regenerates findings; --check verifies
analysis/verify_site.py    flags any number on the site that isn't in findings.json
analysis/check_bindings.py checks every bound number against its data path
tool/index.html            Open Slot, the booking-link kit (built from tool/open-slot.html)
content/copy-and-claims.md approved wording, claims register, banned claims
reference/                 the challenge brief and the full written findings
verification.md            results of every verification gate
CLAUDE.md, PLAN.md         the brief and plan used to build the site with Claude Code
```

Charts are hand-built SVG. Motion uses GSAP 3.12.5 and respects reduced-motion settings. With JavaScript off, every chart falls back to a data table.
